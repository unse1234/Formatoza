  Ubah gambar AVIF ke JPG yang bisa dibuka di semua aplikasi, langsung di browser. Atur kualitas dan warna latar
  untuk area transparan. Tanpa unggah.
h1: Konverter AVIF ke JPG
shortDescription: >-
  Ubah gambar AVIF dari situs web menjadi JPG yang diterima semua aplikasi, printer, dan formulir unggahan.
intro: >-
  AVIF adalah format gambar terbaru yang semakin sering dipakai situs web karena ukurannya sangat kecil. Namun saat
  disimpan ke laptop atau HP, file AVIF sering tidak bisa dibuka di penampil foto bawaan, aplikasi kantor, atau
  editor gambar versi lama. Mengubahnya ke JPG adalah cara paling mudah agar gambar bisa dipakai di mana saja.


  Konverter ini memakai dekoder AVIF bawaan browser Anda, sehingga gambar tidak dikirim ke server. Jika browser
  Anda belum mendukung AVIF, alat ini akan memberi tahu sebelum Anda mulai.
steps:
- >-
  Seret file AVIF ke konverter atau klik “Pilih file” untuk memilih hingga 50 gambar.
- >-
  Bila perlu, buka Pengaturan untuk mengatur kualitas, ukuran, dan warna latar untuk area transparan.
- Klik “Konversi ke JPG”. Semua proses berlangsung di perangkat Anda.
- Unduh setiap JPG atau semuanya sekaligus dalam file ZIP.
sourceExplanation: >-
  AVIF (AV1 Image File Format) adalah format gambar berbasis codec video AV1 yang dikembangkan oleh Alliance for
  Open Media. Pada kualitas yang sama, file AVIF biasanya jauh lebih kecil daripada JPG dan WebP. Format ini didukung
  browser modern, tetapi banyak aplikasi desktop dan penampil foto belum bisa membukanya.
targetExplanation: >-
  JPG (atau JPEG) adalah format foto yang paling umum. Hampir semua perangkat, browser, aplikasi kantor, dan situs
  web bisa membukanya. JPG memakai kompresi lossy 8-bit tanpa transparansi, sehingga cocok untuk foto yang akan
  dibagikan, dicetak, atau diunggah.
useCases:
- title: Gambar yang disimpan dari situs web
  text: >-
    Beberapa situs mengirim AVIF ke browser modern. Ubah ke JPG agar gambar bisa dibuka di aplikasi lain.
- title: Dokumen dan presentasi
  text: >-
    Aplikasi kantor versi lama belum bisa menyisipkan AVIF, sedangkan JPG selalu bisa.
- title: Cetak dan kirim
  text: >-
    JPG diterima oleh layanan cetak, email, dan formulir unggahan mana pun.
limitations:
- >-
  Browser Anda harus mendukung AVIF (Chrome/Edge 85+, Firefox 93+, Safari 16.4+). Jika tidak, alat ini memberi tahu
  sebelum Anda mulai.
- >-
  Area transparan diisi dengan warna latar pilihan Anda (bawaan putih) karena JPG tidak mendukung transparansi.
- AVIF animasi dikonversi menjadi satu gambar diam dari frame pertama.
- >-
  AVIF HDR atau 10/12-bit diubah menjadi sRGB 8-bit, sehingga area terang pada gambar HDR bisa tampak lebih datar.
faq:
- q: Kenapa situs web memberi saya file AVIF?
  a: >-
    Situs memilih format terkecil yang didukung browser Anda. Alamat yang sama bisa mengirim JPG ke browser lama
    dan AVIF ke browser modern.
- q: Apakah kualitas turun saat AVIF diubah ke JPG?
  a: >-
    Sedikit, karena keduanya format lossy dan gambar dikompresi ulang. Pada kualitas 90% perbedaannya tidak terlihat
    dalam penggunaan normal.
- q: Bisakah mengubah AVIF di HP?
  a: >-
    Bisa, di browser HP yang mendukung AVIF, seperti Chrome untuk Android dan Safari di iOS 16.4 atau lebih baru.
